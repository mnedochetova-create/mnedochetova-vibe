# Согласованные тексты: финальный бриф и sharing (MyTravel.Lab)

Статус: **согласовано** (2026-05-28).

Решения:
- Подтверждение брифа **без участников** — да.
- На экране B — **обе** кнопки sharing.
- Кнопка после пересылки — **«✅ Я отправила бриф»**.  
Персона: `BOT_PERSONA.md` — бот в женском роде, пользователь на **ты**.  
Связано: `MENU_ARCHITECTURE.md`.

---

## Когда показываем экраны

| Экран | Условие (логика продукта) |
|-------|---------------------------|
| **A. Готов к подтверждению** | Базовый бриф без критичных пробелов; все подключённые участники подтвердили вклад **или** участников ещё нет, но организатор нажал «готово» из меню (опционально — только если нет ожидающих ответов) |
| **B. Бриф подтверждён** | Организатор нажал **✅ Подтвердить бриф** на экране A |
| **C. Sharing** | Организатор нажал **📤 Поделиться брифом** на экране B (или **📋 Показать текст для пересылки** напрямую) |

Участнику экраны B/C **не показываем** — после своего подтверждения короткое закрытие (см. ниже).

---

## A. Бриф готов к подтверждению (организатор)

**Сообщение:**

> ✅ **Бриф выглядит достаточно полным**
>
> Проверь, что всё верно: состав, даты, бюджет, пожелания участников и ограничения.
>
> Если всё ок — подтверди бриф. После этого его удобно переслать семье, турагенту или партнёру.

**Inline-кнопки (макс. 3):**

| Кнопка | callback | Действие |
|--------|----------|----------|
| ✅ Подтвердить бриф | `brief:confirm` | → экран B |
| ✏️ Дополнить ещё | `brief:edit` | FSM уточнения, без смены статуса |
| 📌 Показать бриф | `event:show_brief` | уже есть |

---

## B. Бриф подтверждён — value moment #3 (организатор)

**Сообщение:**

> 🎉 **Готово — бриф поездки собран**
>
> Теперь у тебя единая картина: кто едет, когда, какой бюджет, что важно участникам и какие ограничения учесть.
>
> Можешь переслать бриф в чат, отправить турагенту или использовать как основу для подбора вариантов.

**Inline-кнопки (MVP, без PDF и публичной ссылки):**

| Кнопка | callback | Действие |
|--------|----------|----------|
| 📤 Поделиться брифом | `brief:share` | → экран C (вводный) |
| 📋 Текст для пересылки | `brief:share_text` | сразу готовый текст + кнопки C2 |
| 📌 Посмотреть бриф | `event:show_brief` | |
| ✨ Новая поездка | `event:create` | новая сессия |

*Правило:* не больше 4 кнопок на одном ряду/экране — при необходимости «Новая поездка» вторым сообщением или отдельным рядом.

---

## C. Поделиться брифом

### C1. Вводный экран (после «📤 Поделиться брифом»)

**Сообщение:**

> 📤 **Поделиться брифом**
>
> Я подготовила текст, который удобно переслать в общий чат или личку — со всей сводкой по поездке.

**Кнопки:**

| Кнопка | callback |
|--------|----------|
| 📋 Показать текст для пересылки | `brief:share_text` |
| 📌 Вернуться к брифу | `event:show_brief` |

*Не показывать:* 🔗 ссылка на бриф, 📄 PDF — пока не реализованы.

### C2. Готовый текст для пересылки

**Сообщение бота:**

> 📋 **Скопируй и отправь**
>
> Ниже текст для пересылки. Можешь отредактировать формулировки перед отправкой.

**Тело `<pre>` (plain text, без HTML внутри):**

```
Привет! Вот сводка по нашей поездке — собрали в MyTravel.Lab.

{brief_plain_text}

Если что-то нужно уточнить — напиши мне (организатору).
```

`{brief_plain_text}` — та же структура, что в карточке брифа (направление, даты, состав, бюджет, пожелания/ограничения, расхождения если есть), без служебных полей.

**Кнопки после текста:**

| Кнопка | callback |
|--------|----------|
| ✅ Я отправила бриф | `brief:share_done` |
| 📌 Вернуться к брифу | `event:show_brief` |

### C3. После «✅ Я отправила бриф»

**Сообщение:**

> Отлично. Если появятся новые пожелания — открой поездку через **📂 Мои поездки** или создай новую кнопкой **✨ Новая поездка**.

**Кнопки:**

| Кнопка | callback |
|--------|----------|
| 📌 Посмотреть бриф | `event:show_brief` |
| ✨ Новая поездка | `event:create` |

## Участник: после подтверждения своего вклада

**Сообщение (вместо B/C):**

> ✅ **Спасибо, я зафиксировала твои пожелания**
>
> Организатор увидит их в общем брифе. Если захочешь что-то добавить — напиши одним сообщением в этот чат.

**Кнопки:**

| Кнопка | callback |
|--------|----------|
| ✏️ Дополнить ещё | `participant:edit` |
| 📌 Посмотреть бриф | `event:show_brief` |

## Согласование с потоком приглашения

| Приглашение (участники) | Финальный бриф (результат) |
|-------------------------|----------------------------|
| «Я отправила **ссылку**» | «Я отправила **бриф**» |
| Текст от первого лица организатора («Я собираю вводные…») | Текст сводки «мы» + подпись организатора |
| Value: не собирать пожелания вручную | Value: единая картина для решений |
