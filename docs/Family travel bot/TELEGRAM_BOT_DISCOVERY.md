# Поиск бота в Telegram — профиль и тексты

Как повысить шанс, что бот **MyTravel.Lab** находят по запросам вроде `travel`, `путешествия`, `семейная поездка`.  
Это **не SEO как в Google**: Telegram в основном матчит **имя** и **@username**; description/about помогают конверсии после клика.

**Персона:** [BOT_PERSONA.md](BOT_PERSONA.md) · **MVP:** [PRODUCT_CARD.md](PRODUCT_CARD.md)

---

## 0) Чеклист перед публикацией

- [ ] Узнать текущий `@username` в [@BotFather](https://t.me/BotFather) → `/mybots` → ваш бот.
- [ ] **`/setname`** — display name с ключевыми словами (ниже §1).
- [ ] **`/setdescription`** — до 512 символов (§2).
- [ ] **`/setabouttext`** — до 120 символов (§3).
- [ ] **`/setuserpic`** — узнаваемый аватар (логотип MyTravel.Lab).
- [ ] **`/setcommands`** — меню команд (§4).
- [ ] **Локализация RU** (и опционально EN) — §5.
- [ ] Не обещать в текстах то, чего нет в проде (бронь, «лучшие цены», готовые маршруты без флага).
- [ ] Ссылка `https://t.me/<USERNAME>` — в канале, bio, сайте, подписи.
- [ ] (Опционально) смена `@username`, если свободен вариант с `travel` — §6.

После правок подождать  несколько часов и проверить поиск: `MyTravel`, `travel lab`, `путешествия`, `семейная поездка`.

## 1) Display name (`/setname`)

**Рекомендуемый (RU-рынок):**

```text
MyTravel.Lab · путешествия & travel
```

**Альтернатива (акцент на семью):**

```text
MyTravel.Lab — семейные путешествия
```

**Альтернатива (короче):**

```text
MyTravel.Lab | travel бриф
```

> Имя видно в **глобальном поиске** Telegram. Кириллица в display name допустима; в `@username` — только латиница.

---

## 2) Description (`/setdescription`)

Текст блока «Что умеет этот бот?» при первом открытии. До **512** символов.

**Вариант A — основной (скопировать в BotFather):**

```text
MyTravel.Lab помогает собрать групповую поездку в Telegram без хаоса в чате.

Для семьи и друзей: travel и путешествия — один общий бриф (даты, бюджет, состав, пожелания, перелёт или машина/поезд/пешком).

Организатор создаёт поездку, приглашает участников по ссылке, все дополняют вводные. Бот структурирует пожелания и готовит согласованный бриф перед выбором направления.

Подходит, если вы планируете путешествие вместе и устали сводить сообщения вручную.
```

**Вариант B — короче (если A не влезает):**

```text
Семейные и групповые путешествия в Telegram: общий travel-бриф для всех участников.

Собери даты, бюджет, состав и пожелания (перелёт, авто, поезд). Пригласи близких по ссылке — бот сведёт ответы в один понятный бриф для выбора направления.
```

---

## 3) About (`/setabouttext`)

Короткая строка в профиле бота и при пересылке ссылки. До **120** символов.

**Рекомендуемый:**

```text
Путешествия с семьёй: общий бриф в Telegram. Travel-план без хаоса в чате — MyTravel.Lab
```

**Запасной (если обрезает клиент):**

```text
Семейные путешествия · travel-бриф · согласование поездки в Telegram
```

---

## 4) Команды (`/setcommands`)

Скопировать **целиком** в BotFather после выбора бота (формат: `команда - описание`):

```text
start - Создать поездку или продолжить
help - Помощь, если застрял
cancel - Отменить текущий ввод
```

Соответствует `bot.set_my_commands` в `bot/src/main.py`.

В BotFather: `/mybots` → бот → **Bot Settings** → **Edit Language** (или команды локализации, если доступны в вашей версии).

Либо через Bot API: `setMyName`, `setMyDescription`, `setMyShortDescription` с `language_code`: `ru`, `en`.

Invite family and friends, collect input, align before picking a destination. Built for family travel and group vacations.

Family travel brief in Telegram. Group trips, shared criteria, less chat chaos.

## 7) Чего не писать (согласовано с MVP)

| Не обещать | Почему |
|------------|--------|
| «Забронируй тур/билет здесь» | брони нет в MVP |
| «Лучшие цены на авиа» | Travelpayouts — backlog |
| «Готовые маршруты с ценами» | этап после брифа, за флагом |
| «PDF / публичная ссылка на бриф» | пока не в продукте |

Допустимо: **бриф**, **участники**, **приглашение**, **согласование**, **направление / travel-план** (как следующий этап).
