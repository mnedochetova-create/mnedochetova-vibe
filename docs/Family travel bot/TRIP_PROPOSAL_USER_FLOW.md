# User flow — опыт после брифа (LLM + карточки)

Продолжение [`USER_FLOWS.md`](USER_FLOWS.md) (шаги 13+).  
Архитектура: [`TRIP_EXPERIENCE_ARCHITECTURE.md`](TRIP_EXPERIENCE_ARCHITECTURE.md).  
В боте: `TRIP_PROPOSALS_ENABLED=true`.

**Важно:** единственный жёсткий checkpoint — **подтверждённый бриф**. Дальше все шаги — гибкие, контент от LLM в HTML-карточках.

---

## Шаг 13 — Снимок и готовность (по типу поездки)

| | |
|--|--|
| **Кто** | Организатор |
| **Когда** | После «Подтвердить бриф» или из «Мои поездки» |
| **Бот** | `recommendation_ready` + `trip_archetype` + `transport.modes_present` (перелёт, машина, поезд, лодка, пешком, …) |
| **Карточка** | `readiness_blocked` — только по **заявленным** режимам ([`TRIP_TRANSPORT_MODEL.md`](TRIP_TRANSPORT_MODEL.md)) |
| **Результат** | `blocked` или переход к 14 |

---

## Шаг 14 — Сценарии поездки (2–3)

| | |
|--|--|
| **Кто** | Организатор |
| **Действие** | «Собрать сценарии» / `trip:show_draft:{code}` |
| **Бот** | LLM Planner: гипотезы (комбо IT→HR→FR vs другой порядок; или маршрут Иваново–Городец) |
| **Карточка** | `scenario_compare` — заголовок, fit, tradeoffs, теги |
| **Результат** | выбор или «показать маршрут для p1» |

*Не показываем:* цены, «забронировать».

---

## Шаг 15 — Маршрут по сегментам

| | |
|--|--|
| **Кто** | Организатор |
| **Действие** | «Развернуть маршрут» / `trip:route:{code}:{proposal_id}` |
| **Бот** | `route_plan`: сегменты, перемещения, дни, must-visit из брифа |
| **Карточки** | `route_overview` + N × `route_segment` |
| **Результат** | понимание порядка точек/стран |

**Корнер-кейсы:**

- **Авто / поезд / пешком / РФ** — сегменты = локации; режимы из брифа, без вопроса про перелёт.
- **Комбо EU** — на каждом стыке свой режим: `ferry`, `train`, `car`, `flight` (не один шаблон).
- **Лодка / паром** — сегмент `boat_private`/`ferry` + caveats, без выдуманного расписания.
- **Перелёт** — только если `flight` ∈ `modes_present`; иначе нет блока «вылет из Москвы» до short-list.

## Шаг 16 — «Что расскажем» (нарратив)

| | |
|--|--|
| **Кто** | Организатор |
| **Действие** | «Почему такой маршрут» / автоматически после 15 |
| **Бот** | LLM Narrator: сезон (конец августа), география, погода **как сезон**, связь с брифом |
| **Карточка** | `story` + при конфликтах `group_note` |
| **Результат** | можно обсудить с группой текстом из бриф-sharing |

Пример содержания: «Удобнее войти в Италию, затем Хорватия, затем Франция — меньше обратных перелётов, плотность мест по вашим пожеланиям».

## Ветки

- **Дополнили бриф после подтверждения** — `trip:refresh:` → пересбор снимка, сценариев, маршрута.
- **Конфликты в группе** — сценарии показываем с `group_note`; short-list с предупреждением.
- **Сменить порядок стран** — новый запрос к Planner, не правка брифа молча.

## Связь с кодом v0

Сейчас в боте реализованы упрощённые **шаги 13–14** (rules-карточки). Шаги 15–18 — в спеке, внедрение по roadmap §7 в [`TRIP_FROM_BRIEF_SPEC.md`](TRIP_FROM_BRIEF_SPEC.md).

## Не в этом flow

- Новый `event` — «✨ Новая поездка».
- Полный пересбор брифа — только supplement / участники.
