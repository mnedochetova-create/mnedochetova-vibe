# Агенты (промпты)

Скиллы для Cursor перенесены в репозиторий:

| Роль | Путь |
|------|------|
| Marketing Content Creator | [.cursor/skills/marketing-content-creator/SKILL.md](../../.cursor/skills/marketing-content-creator/SKILL.md) |
| Product Trend Researcher | [.cursor/skills/product-trend-researcher/SKILL.md](../../.cursor/skills/product-trend-researcher/SKILL.md) |

Редактируйте **только** `SKILL.md` в `.cursor/skills/<имя-скилла>/` — так они появляются в **Cursor → Settings → Skills** для этого проекта.

Проверка: в папке скилла обязательно есть файл `SKILL.md` (не пустая директория). `name` во frontmatter должен совпадать с именем папки (латиница, дефисы).

Файлы `marketing-content-creator.md` и `product-trend-researcher.md` в этой папке — устаревшие копии, оставлены как указатели.
