# Модель синергий Нумероид

## Контекст и задача

Группа развивает два сервиса в корпоративном тревеле:

- `Numeroid` — цифровой сервис управления командировками с прямым контуром работы через TravelLine и возможностью моментального подтверждения 3D-контрактов в отелях.
- `Aerotone` — сервис делового туризма с фокусом на сервисную модель и работу через экосистему `Corteos` и `Raketa`.

Цель: разделить роли двух сервисов, минимизировать внутреннюю конкуренцию, усилить синергии и ускорить рост клиентской базы группы.

Источники:
- [Numeroid](https://numeroid.ru)
- [Aerotone](https://ru.aerotone.ru)
- [Corteos](https://corteos.travel)
- [Raketa](https://www.raketa.world)

## Продуктовая стратегия позиционирования

### Numeroid — digital speed core

Использовать `Numeroid` как high-speed digital контур для компаний, где критичны:

- быстрое бронирование;
- мгновенные подтверждения;
- self-service сценарии;
- прозрачный контроль travel-расходов.

Ключевая дифференциация: прямой контур через TravelLine + быстрый отельный инвентарь с 3D-контрактами.

### Aerotone — high-touch service core

Закрепить `Aerotone` как high-touch TMC-сервис для сценариев, где важнее персональное сопровождение, чем полностью автоматический контур:

- сложная оргструктура;
- нестандартные маршруты;
- MICE/concierge-задачи;
- расширенный документооборот и сервисное сопровождение.

## Разделение клиентских сегментов

### В `Numeroid` приоритетно направлять:

- digital-first SMB и mid-market компании;
- клиентов с повторяемыми стандартными командировками;
- компании, готовые к быстрому запуску без сложного внедрения;
- клиентов с запросом на скорость и автоматизацию.

### В `Aerotone` приоритетно направлять:

- крупные компании со сложной структурой согласований;
- клиентов с высоким объемом нестандартных запросов;
- бизнесы, требующие персонального менеджмента и кастомного SLA;
- клиентов с расширенным сервисным периметром.

## Модель синергии между сервисами

1. **Единый коммерческий вход**  
   Одна воронка лидов, маршрутизация по диагностическому чек-листу (сложность, срочность, требуемый сервисный уровень).

2. **Двусторонние трансферы клиентов**  
   - `Numeroid -> Aerotone` для сложных кейсов.  
   - `Aerotone -> Numeroid` для стандартизируемых клиентов.

3. **Единый центр закупок и переговоров**  
   Общая контрактная сила группы по поставщикам и 3D-соглашениям при раздельных рыночных офферах.

4. **Единый BI-контур**  
   Сквозная отчетность по воронке, марже, SLA и retention на уровне группы.

5. **Сквозные стандарты качества**  
   Единые KPI и SLA, чтобы клиентский опыт был предсказуемым независимо от бренда.

## Roadmap на 90 дней

### 0-30 дней

- финализировать сегментацию текущей базы;
- утвердить правила маршрутизации лидов;
- подготовить пакет офферов и скрипты пресейла для двух брендов.

### 31-60 дней

- запустить пилот кросс-продаж на 10-15 аккаунтах;
- настроить BI-дашборд по конверсии, трансферам и SLA;
- собрать кейсы ранних синергий.

### 61-90 дней

- масштабировать модель на новые сегменты;
- скорректировать коммерческие условия и SLA по факту пилота;
- зафиксировать и публично упаковать успешные кейсы.

## KPI для контроля синергии

- доля корректно маршрутизированных лидов;
- конверсия SQL -> договор по каждому бренду и в группе;
- доля успешных кросс-переходов без потери клиента;
- валовая маржа по каналам бронирования;
- время подтверждения поездки/отеля;
- NPS и retention по сегментам.

## Первые управленческие решения

1. Утвердить матрицу сегментов и правила маршрутизации.
2. Назначить owner синергии на 90 дней с еженедельным review.
3. Запустить единый пресейл-процесс: сначала диагностика, затем правильный контур.
